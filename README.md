# Who Owns History?

An eight-slide HTML presentation about the debate over museum treasures.

## View

Open `index.html` in a browser. Everything is static and works without a build step or external runtime services.

- Previous / next: buttons, arrow keys, Page Up / Page Down or touch swipe.
- First / last: Home / End.
- Direct selection: keys 1–8 or the progress segments.
- Full screen: F or the Full screen button where supported.
- Sources: the Sources button, including image credits.
- Speaking script: `speaking-script.txt` (two alternating presenters).

The visual design follows the supplied historical collage reference: dusty blue, cream paper, narrow serif headings, handwritten-style accents and archival images. All historical case-study images have source and license information in the Sources dialog. The opening collage is an AI-generated illustration; it is not used as historical evidence.

The script uses B2-level language and three words from the supplied vocabulary list: **troops**, **captured**, **looted**. Past Simple, passive voice and the second conditional are documented in the learning notes after the script.

The photographs from Cleveland illustrate Benin artworks, not the individual objects in the Smithsonian's 2022 ownership transfer. The latter is described as a dated example, not as a statement of the collection's current physical location.
